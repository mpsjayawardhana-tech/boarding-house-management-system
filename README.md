# Boarding House Management System

A dynamic, fully-featured Next.js application for managing a boarding house, including dynamic rosters, inventory tracking, financial heatmaps, and role-based access control.

## Features
- **Dynamic User Management**: Add/Remove active boarders.
- **Roster & Task Delegation**: Daily and Weekly intelligent scheduling with strict "No-Overlap" algorithms.
- **Inventory & Debt Quotas**: Track who bought what, manage surplus (advance payments), and automatically calculate missing debts.
- **Finance Heatmap**: Interactive RBAC-enabled visual grid to track monthly boarding fee payments.

## Tech Stack
- Next.js 14
- Tailwind CSS
- Zustand (Persisted State Management)
- Shadcn UI / Lucide Icons
